# 🚀 Scriptly AI

**Scriptly AI** is an AI-powered web application that helps creators generate high-quality YouTube video scripts in seconds. Simply enter a topic, choose the script length, tone, and target audience, and Scriptly AI will generate a well-structured script using Google's Gemini AI.

🌐 Live Demo

Website: https://paraspatira.github.io/scriptly-ai/

📂 GitHub Repository

https://github.com/paraspatira/Scriptly

---

## ✨ Features

* 🤖 AI-powered script generation using Google Gemini AI
* 📝 Generate scripts for any topic
* 🎭 Multiple writing tones (Professional, Casual, Educational, Storytelling, etc.)
* 📏 Adjustable script length
* 🎯 Target audience selection
* ⚡ Fast and responsive user interface
* 📱 Fully responsive design for desktop and mobile

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/scriptly-ai.git
```

### 2. Navigate to the project

```bash
cd scriptly-ai
```

### 3. Install frontend dependencies

```bash
cd frontend
npm install
```

### 4. Install backend dependencies

```bash
cd ../backend
pip install -r requirements.txt
```

### 5. Configure the Gemini API key

Create a `.env` file in the backend folder and add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### 6. Start the backend

```bash
uvicorn main:app --reload
```

### 7. Start the frontend

```bash
npm run dev
```
